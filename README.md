# RiftZone Store

Node.js demo shop for accounts and game items.

## Run locally

```powershell
npm install
npm start
```

Open:

```txt
http://127.0.0.1:4173/
```

## Demo admin

```txt
Username: admin
Password: admin123
```

## Deploy

This project is ready for Node hosting such as Render or Railway.

Start command:

```txt
npm start
```

The server uses `process.env.PORT`, so cloud platforms can assign the port automatically.
